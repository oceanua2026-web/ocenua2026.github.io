### ТЕСТ 22.02

**Перевірюваний аспект:** Яке призначення маски вводу 00:00 для часу?

**Запитання:** Яке призначення маски вводу 00:00 для часу?

**А.** Задати обов’язковий шаблон із двох цифр, двокрапки та двох цифр

**Б.** Перетворити введений час на незмінне значення опівночі

**В.** Автоматично записати поточний час без введення користувачем

**Г.** Перевірити лише допустимість дати без шаблону введення часу

**Правильна відповідь:** А. Задати обов’язковий шаблон із двох цифр, двокрапки та двох цифр

**Повне пояснення:** Маска керує формою введення; допустимість часу додатково забезпечується типом даних і перевірками.

### ТЕСТ 22.03


**Параграф:** § 22. Зв’язування та заповнення таблиць

**Джерело:** ДЖЕРЕЛО 22.03

**Перевірюваний аспект:** Що таке первинний ключ?

**Запитання:** Що таке первинний ключ?

**А.** Будь-яке перше поле незалежно від унікальності значень

**Б.** Назва таблиці, спільна для всіх її записів

**В.** Поле, яке може однаково позначати кілька різних записів

**Г.** Поле або сукупність полів, що однозначно ідентифікує запис

**Правильна відповідь:** Г. Поле або сукупність полів, що однозначно ідентифікує запис

**Повне пояснення:** Ключ має бути унікальним і не порожнім. Складений ключ використовує кілька полів, якщо одного недостатньо.

### ТЕСТ 22.04


**Параграф:** § 22. Зв’язування та заповнення таблиць

**Джерело:** ДЖЕРЕЛО 22.04

**Перевірюваний аспект:** Як відкрити таблицю Access для введення записів?

**Запитання:** Як відкрити таблицю Access для введення записів?

**А.** Відкрити конструктор таблиці для зміни лише структури полів

**Б.** Відкрити попередній перегляд звіту без редагування записів

**В.** Подвійно клацнути її назву в області переходів для режиму таблиці

**Г.** Відкрити вікно зв’язків для зміни лише відношень таблиць

**Правильна відповідь:** В. Подвійно клацнути її назву в області переходів для режиму таблиці

**Повне пояснення:** Режим таблиці показує записи та дає змогу вводити значення полів.

**Основа:** Індивідуальна змістова звірка 2026-10-04; Інформатика Бондаренко О.О.9кл2026.pdf; PDF-сторінки: 135, 140. Запитання, варіанти й пояснення сформульовано самостійно.

### ТЕСТ 22.06


**Параграф:** § 22. Зв’язування та заповнення таблиць

**Джерело:** ДЖЕРЕЛО 22.06

**Перевірюваний аспект:** Для чого використовують підстановку в полі?

**Запитання:** Для чого використовують підстановку в полі?

**А.** Для обчислення підсумків усіх числових полів без вибору значень

**Б.** Для вибору допустимого значення зі списку або пов’язаної таблиці

**В.** Для видалення повторюваних записів без визначення допустимих значень

**Г.** Для зміни лише зовнішнього оформлення заголовка поля

**Правильна відповідь:** Б. Для вибору допустимого значення зі списку або пов’язаної таблиці

**Повне пояснення:** Список полегшує введення та зменшує помилки, наприклад під час вибору предмета за його кодом.

**Основа:** Індивідуальна змістова звірка 2026-10-04; Інформатика Бондаренко О.О.9кл2026.pdf; PDF-сторінки: 142, 143, 144. Запитання, варіанти й пояснення сформульовано самостійно.
